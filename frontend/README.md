# Frontend

Skeleton Next.js local do Tops do Job V3.

Escopo da Fase 1B:

- estrutura mínima de Next.js;
- página local de skeleton;
- página local `/health`;

- nenhuma autenticação completa;
- nenhuma integração externa.

Comando futuro, somente quando as dependências já estiverem autorizadas/disponíveis:

```powershell
npm run dev
```
