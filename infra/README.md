# Infraestrutura

Este diretório guarda arquivos de infraestrutura por ambiente.

- `local`: ambiente local isolado para desenvolvimento futuro.
- `staging`: reservado para definição futura, sem deploy nesta fase.
- `producao`: reservado para definição futura, sem acesso ou publicação nesta fase.

A Fase 1A prepara apenas a infraestrutura local. Nenhuma conexão externa, VPS, produção, Efí real ou banco de produção deve ser acessado.
