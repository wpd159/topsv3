# SEO - template de exportacao do Search Console

## Regra

O Search Console nao deve ser acessado automaticamente por script nesta fase.

A exportacao completa deve ser manual, feita pelo usuario quando houver autorizacao operacional.

## Baseline ja registrado por prints

Ultimas 24 horas:

- 92 cliques;
- 432 impressoes;
- CTR 21.3%;
- posicao media 8.7.

Consultas fortes de marca/relacionadas:

- tops do job;
- topsdojob;
- acompanhantes do job;
- acompanhante job;
- acompanhante do job;
- acompanhantes job;
- job acompanhante;
- job acompanhantes;
- site de acompanhantes job;
- site de acompanhante job.

Leitura: o trafego atual parece mais forte em marca e variacoes do que em intencao local.

Objetivo da V3: aumentar consultas de intencao local como `acompanhante em [cidade]`.

## Exportacoes manuais necessarias

Exportar no Search Console:

- Consultas;
- Paginas;
- Paises;
- Dispositivos;
- Datas.

Periodos:

- 3 meses;
- 28 dias;
- 7 dias;
- ultimas 24 horas, quando aplicavel.

## Campos minimos esperados

| Aba | Campos |
| --- | --- |
| Consultas | consulta, cliques, impressoes, CTR, posicao |
| Paginas | URL, cliques, impressoes, CTR, posicao |
| Paises | pais, cliques, impressoes, CTR, posicao |
| Dispositivos | dispositivo, cliques, impressoes, CTR, posicao |
| Datas | data, cliques, impressoes, CTR, posicao |

## Uso no cutover

Comparar antes/depois:

- consultas de marca;
- consultas locais;
- paginas de cidade;
- paginas de bairro;
- paginas de anuncio;
- cobertura de sitemap;
- 404/5xx;
- queda abrupta de posicao media.

Cutover SEO fica bloqueado se nao houver baseline exportado e revisado.
