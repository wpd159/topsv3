# SEO - cidades prioritarias

## Regra

Este documento nao define ranking definitivo. Ele registra amostras publicas do sitemap e criterios de priorizacao para analise futura com Search Console.

## Criterios de prioridade

- cidade ja observada no sitemap;
- cidade com consultas no Search Console;
- cidade com anuncios publicados/indexaveis;
- cidade com bairros fortes;
- cidade estrategica por negocio;
- cidade com risco de perda de trafego se a URL mudar.

## Pendencias

- Exportar Search Console por paginas e consultas.
- Cruzar paginas de cidade com cliques/impressao.
- Identificar cidades com busca local `acompanhante em [cidade]`.
- Evitar criar paginas de cidade sem conteudo util.
- Revalidar cidades com dados sanitizados apos restore local isolado.
- Nao promover cidade/bairro a prioridade definitiva sem dados sanitizados ou Search Console.
